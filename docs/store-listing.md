## Long description

**Material Weather** is a compact toolbar popup with a Material-inspired weather card: current conditions, a five-hour strip, and a multi-day outlook — no sign-up, no API key, free to use.

### Features

- Search by city name (Open-Meteo geocoding) and add places to your list
- Save multiple locations, reorder them, remove them, and pick which one is active
- Current temperature, “feels like,” condition, and today’s high/low
- Hourly strip for the next five hours; daily rows for the next several days (forecast data covers up to seven days)
- Toggle °C / °F — preference is remembered
- Light, dark, or system-matched theme — preference is remembered
- Compact popup; forecast cache reduces repeat requests

### Privacy

No accounts and no analytics. Saved locations, theme, unit, and cached forecasts stay in your browser (`storage.local`). The only network calls are to Open-Meteo:

- `https://geocoding-api.open-meteo.com` — city search  
- `https://api.open-meteo.com` — forecast for the coordinates you selected
